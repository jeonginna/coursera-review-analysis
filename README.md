# 평점이 놓친 이탈 신호 — 온라인 강의 플랫폼 VOC 분석

> 별점만으로는 보이지 않는 **'숨은 불만'**을 리뷰 텍스트에서 발굴해,
> 품질 이슈 강좌를 선별하고 개선 우선순위를 도출한 프로젝트

**분석 기간** 2026.06.01 ~ 2026.06.09 · **도구** Python (VADER, Pandas, langdetect) · **데이터** 강좌 623개 / 리뷰 1,454,711건

> **데이터 관련** — Kaggle 공개 데이터셋(Coursera Course Reviews, 2015~2020)을 사용했다. 원본 데이터는 아래 링크에서 직접 내려받을 수 있다.
> 🔗 [Course Reviews on Coursera (Kaggle)](https://www.kaggle.com/datasets/imuhammad/course-reviews-on-coursera)

<br>

## 🎯 핵심 결과

| 지표 | 값 | 의미 |
|---|---|---|
| **분석 대상** | 145만 건 | 총 리뷰 건수 |
| **고평점 비율** | 94.4% | 4~5점이 전체의 대부분 → 평균으로는 변별 불가 |
| **숨은 불만** | 12,028건 | 별점은 높지만 본문 감성은 부정 |
| **핵심 불만 3유형** | 72.8% | 과제·난이도·분량이 불만의 대부분 |

<br>

## 🔍 배경 & 문제 정의

운영 관리자가 수백 개 강좌의 리뷰를 모두 확인하기엔 한계가 있고, 별점은 대부분 높게 형성돼 실제 품질 이슈를 발견하기 어렵다. 이 프로젝트는 평점과 리뷰 텍스트를 함께 분석해 품질 이슈 강좌를 선별하고, **별점은 높지만 본문에는 불만이 담긴 케이스**를 탐지하는 것을 목표로 한다.

<br>

## 🔄 분석 과정

| 단계 | 내용 |
|---|---|
| **1. 데이터 탐색** | 별점 분포·결측·중복 점검, 두 테이블 정합성 확인, 빈출 키워드 파악 |
| **2. 위험 강좌 선별** | 강좌별 부정 비율·개수 집계 후 리뷰 수 기준선을 잡아 4그룹 분류 |
| **3. 감성 분석** | VADER로 숨은 불만 추출, `langdetect`로 언어 식별해 비영어 리뷰 오차 보정 |
| **4. VOC 유형화** | 키워드 기반 불만 유형 분류 |
| **5. 우선순위 선정** | 유형별·강좌별 개선 우선순위 도출 |

<br>

## 💡 주요 발견

**1. 별점 평균은 변별력이 없다**

| 별점 | 비중 |
|---|---|
| 5점 | 78.8% |
| 4점 | 15.6% |
| 3점 | 3.3% |
| 2점 | 1.1% |
| 1점 | 1.2% |

4·5점이 94.4%를 차지해 평균값으로는 강좌 간 품질 차이를 구분할 수 없었다. 3점(3.3%)이 1~2점 합(2.3%)보다 많아, **1~3점을 부정 리뷰로 재정의**했다.

**2. 비율과 개수를 함께 봐야 한다**

부정 비율만 보면 표본 크기에 속을 수 있다(리뷰 6건짜리 강좌가 부정 100%). 비율·개수 두 축을 결합해 569개를 균형 있게 분류한 결과, **최우선 개선군 192개**를 선별했다.

| 그룹 | 강좌 수 |
|---|---|
| 최우선 개선군 (비율↑ 개수↑) | 192 |
| 비율 위험 (비율↑ 개수↓) | 95 |
| 규모 위험 (비율↓ 개수↑) | 93 |
| 양호 | 189 |

**3. 감성 점수의 언어별 오차를 보정했다**

리뷰 언어는 영어 64%, 스페인어 31%, 포르투갈어 3%로 구성돼 있었다. VADER는 영어 기반 모델이라, **감성 점수가 낮아도 내용은 칭찬인 비영어 리뷰가 약 1/3**을 차지했다. `langdetect`로 언어를 식별해 영어 리뷰로만 필터링하고, 실제 부정 리뷰를 12,028건으로 확정했다.

**4. 불만의 73%는 콘텐츠 설계 영역**

| 불만 유형 | 비중 |
|---|---|
| 과제/퀴즈 | 31.9% |
| 난이도 | 25.5% |
| 분량/시간 | 15.4% |
| 영상/자료 | 13.3% |
| 오류/정확성 | 8.2% |
| 설명/강의 | 6.6% |

*리뷰 1건에 복수 유형이 포함될 수 있어 합계가 100%를 초과한다.*

상위 3유형이 72.8%로, 강사 역량이나 플랫폼 문제가 아니라 **학습자가 마주치는 진입장벽과 설계 부족**에 가까웠다. 강의를 새로 찍는 것보다 저비용으로 보강 가능한 영역이다.

## 🛠 개선 제안

| 문제 유형 | 개선안 |
|---|---|
| 과제/퀴즈 | 선수지식 안내 · 난이도 표기 세분화 |
| 난이도 | 단계별 힌트 · 상세 해설 보강 |
| 분량/시간 | 예상 소요 시간·학습 기간 명시, 학습 분량 조정 |
| 영상/자료 | 오래된 영상 갱신 |
| 오류/정확성 | 오답·오류 정기 검수 프로세스 구축 |

분류 로직 자체는 운영에서 반복 활용할 수 있다. 숨은 불만이 증가하는 강좌를 조기에 점검하거나, 반대로 고평점·긍정 리뷰를 자동 추출해 마케팅 소재나 리뷰어 리워드에 활용하는 방향이다.
